开发环境 · 仓库根目录
.devcontainer/devcontainer.json定义 Codespace：Python 3.12 + Node 24、4 核，转发端口 3000（Lab-02）和 8080（Lab-01 预览）创建时跑 on-create.sh（装 .venv、Lab-02 依赖、Chromium）和 post-create.sh（建 .env）
.devcontainer/set-key.sh把 Copilot 令牌写进 Lab-02-Knowledge-Summary/.env，没有 LAB_API_KEY 就随机生成一把开场 0.4 手动运行；Next.js 启动时加载 .env，lib/copilot.ts 用令牌，lib/api.ts 用密钥
.vscode/mcp.json注册 MCP 服务器 industry-insight：用 .venv 的 Python 以 stdio 方式启动 server.pyVS Code 的 Copilot Chat 读它；加了新工具要在这里点 Restart
.github/prompts/industry-insight.prompt.md斜杠命令 /industry-insight：读清单 → 抓取 → 逐个行业研判 → 生成周报在 VS Code Chat 里输入它；它指挥模型调用 industry-insight 的 4 个工具
Lab-01-Industry-Insight · 行业洞察智能体
focus.md你会改行业关注清单：每个「## 行业」的搜索词、排除词、关注点，加上汇报对象和分析要求parse_focus() 读搜索词和排除词；模型读关注点和分析要求
mcp_server/industry_tools.py你会改全部逻辑：解析清单、抓取去重并编号、校验研判并回填原文链接、渲染周报（不合格走兜底）被 server.py 和 cli.py 调用；读 input/sources.json，写 output/，把周报复制到 frontend/
mcp_server/server.py · cli.py你会改同一套函数的两个入口：server.py 注册成 MCP 工具，cli.py 做成 python cli.py <工具名> [JSON]VS Code 按 mcp.json 启动 server.py；gh-aw 的 mcp-scripts 调 cli.py
frontend/report.md · report.json已发布的周报（入库）；output/ 下是本地运行的同名文件（不入库）周报网页 index.html + main.js 读 report.md；Lab-02 的 lib/insight.ts 读 report.json
.github/workflows/industry-insight.mdgh-aw 源文件：定时（每周一北京时间 08:00）、网络白名单、mcp-scripts、safe-outputs 开 PR，正文是给云端智能体的说明gh aw compile 生成 industry-insight.lock.yml，GitHub Actions 实际运行的是它
Lab-02-Knowledge-Summary · 知识总结智能体
.github/skills/knowledge2ppt/SKILL.md你会改团队汇报规范 + 工作流程：读素材 → 写 outline.md → 调 pptx skill → 保存 .pptxVS Code Chat 自动选中它；网页服务经 SDK 的 skillDirectories 读同一份
.github/skills/pptx/通用 PPT 能力：scripts/html2pptx.js 把每页 HTML 转成可编辑的 .pptx被 knowledge2ppt 调用；靠 NODE_PATH 用 Lab-02 装好的 playwright、pptxgenjs
app/api/…/route.ts（4 个）insight/latest 读周报；jobs/insight、jobs/webpage 提交任务、立即回 202；jobs/[id] 查进度Studio 的 4 个工具调用；都先过 lib/api.ts 的 checkApiKey()（另有通用的 POST /api/jobs，curl 调试用）
app/page.tsx · app/jobs/[id]/page.tsx · app/api/download/route.ts首页（经 /api/generate/stream 用 SSE 看进度）、任务进度页（每 5 秒刷新）、.pptx 下载在浏览器里直接打开，不检查密钥；读 lib/jobs.ts、lib/ppt-files.ts，首页调 lib/generate.ts
lib/job-request.ts · lib/jobs.tshandleCreateJob() 鉴权、校验页数和风格后 createJob()；任务排队一次只跑一个，状态写进 output/jobs/被 POST /api/jobs* 和进度页调用；run() 调 generate.ts
lib/generate.ts一次生成的完整流程：建会话目录 → 准备素材（周报写成 source.md）→ 调 copilot.ts → 等 .pptx 落盘被 jobs.ts 和首页的 SSE 接口调用；用 insight.ts、ppt-files.ts
lib/copilot.ts启动 Copilot SDK 客户端、选模型，createSession() 挂上 .github/skills，发提示词、转发事件被 generate.ts 调用；用 @github/copilot-sdk，SDK 再启动 Copilot CLI 子进程
lib/insight.ts读 Lab-01 周报（output/ 优先，frontend/ 兜底），按行业筛选，转成 Markdown 素材被 /api/insight/latest、/insight 页和 generate.ts 调用
lib/styles.ts你会改PPT 风格（咨询、极客、杂志）和页数范围 1~30首页表单、job-request.ts、SSE 接口用；Lab-02 第 3 步在这里加「公司品牌风」
Lab-03-Copilot-Studio · 串起来
openapi.yaml你会改连接器定义（Swagger 2.0）：4 个操作 GetIndustryInsight、CreateInsightPresentation、CreateWebPagePresentation、GetPresentationJob，鉴权用请求头 x-api-key导入 Studio 变成 4 个工具；host 改成自己的 Codespace，title 带上名字
README.md「智能体指令」粘贴进 Studio 的 Instructions：什么时候调哪个工具、页数和风格的默认值、怎么回答Studio 的编排器读它，再结合 openapi.yaml 里的工具描述做决定
