几个词先认识一下

Codespace：浏览器里的一台云电脑，VS Code 和所有依赖都装好了，关掉网页它还在。
Copilot Chat · Agent 模式：右边的对话框。你说要什么，它自己读文件、改代码、跑命令，每次跑命令前都会问你同不同意。
Prompt 文件（斜杠命令）：写好的工作说明书。输入 /industry-insight，它就照着干活。
MCP 工具：给 AI 用的「插座」。我们把抓新闻、出周报写成函数，AI 读了说明就知道什么时候该调用。
gh-aw：放在 GitHub 上、按时间表自动运行的智能体（这里是每周一早上 8 点）。
Skill：写给 AI 的岗位手册（SKILL.md），规定做汇报 PPT 的步骤和团队规范。
Copilot SDK：让我们自己写的程序（网页服务）也能调用 Copilot，用的是同一份 Skill。
API 和 x-api-key：别的系统调用你服务的「窗口」和「门禁卡」。Studio 调用的接口没有门禁卡一律拒绝。
Copilot Studio：微软的低代码智能体平台，业务同事在这里和「业务汇报助手」对话，不用碰代码。
连接器和连接：连接器是 Studio 按 openapi.yaml 生成的「插头」，连接是插头里存的那把 API 密钥。
